About the Bodycam build calculator

Bodycam Build Calculator is a free, unofficial weapon build planner for Bodycam, the multiplayer FPS game by Reissad Studio. Pick a weapon, try attachments — barrels, muzzles, grips, stocks, magazines, optics — and see how they change recoil, ADS speed, reload time, equip speed, hip fire spread and damage. It can also find the best build for a goal such as minimum recoil or fastest ADS, save builds, compare them and share a build as a link. All stats are extracted from the game files.

How it is calculated

The data is extracted from the game files (the item table + a GameplayEffect for every weapon and attachment). Multipliers of one stat are summed as in GAS: result = base × (1 + Σ(multiplier − 1)), so −10% and −10% give −20%, not −19%.

"Reload / ADS / equip speed" are speed multipliers: time = base time ÷ multiplier. Base reload and draw times are the lengths of the game's animations (averaged over the calm/stressed variants); the weapon may actually become ready slightly before the animation ends. Base ADS time comes from the curve that moves the weapon into the sights: the moment 95% of the path is covered (the rest is fine settling).

Compatibility follows the game's tags (attachment ↔ weapon). A slot is available only if the weapon or an installed part has a mounting point for it (model sockets from the game files); parts in unavailable slots are not counted.
